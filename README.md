# رِحلَة — ابدأ رحلتك في الذكاء الاصطناعي

تجربة تعلّم عربية تفاعلية (`dir="rtl"`) مبنية بالكامل من حزمة المنهج المعتمدة (`ai_course_full_materials_2026-10-05`) للهاتف وسطح المكتب، بلا تسجيل حساب ومع حفظ محلي كامل على الجهاز.

## التشغيل المحلي

- **عبر خادم محلي (موصى به لتفعيل جميع مزايا الصوت والتعرف الصوتي في المتصفح):**
  ```sh
  python3 -m http.server 8080
  ```
  ثم افتح `http://localhost:8080` في المتصفح.

- **فتح مباشر دون خادم:**
  يمكن أيضاً فتح الملف `index.html` مباشرة في المتصفح (حُزمت بيانات الوحدات العشر ومفاتيح المقاطع الصوتية محلياً في `js/course-data.js` و`js/audio-manifest.js`). ملاحظة: ميزة الإجابة بالمايكروفون (`Web Speech Recognition`) تتطلب متصفحاً داعماً عبر `http://localhost` أو `https` واتصالاً بالشبكة، وعند عدم توفرها يظهر بديل الاختيار المباشر بوضوح.

## بنية المشروع

- `index.html` — المدخل الرئيسي والمعالم الدلالية ونوافذ `<dialog>` الأصلية.
- `css/styles.css` — نظام التصميم الأصلي («رحلة»)، الخطوط العربية المضمّنة (`Baloo Bhaijaan 2` و`IBM Plex Sans Arabic`)، الوضع الداكن، والطباعة.
- `content/U01.json` – `content/U10.json` — محتوى الوحدات العشر المهيكل (141 محطة، 621 خطوة تفاعلية، و45 مكوّن تقييم ختامي مع النماذج البديلة وبوابات السلامة).
- `js/` — وحدات إدارة الملف المحلي والنسخ الاحتياطي (`store.js`)، قواعد فتح الوحدات والمحطات (`course.js`)، المحرك الصوتي والتحدث (`audio.js`)، التفاعلات العشر والتصحيح (`interactions.js`)، إصدار الشهادات (`cert.js`)، والموجه والواجهات (`app.js`).
- `assets/` — الشخصيات الست والأيقونات الثلاثية الأبعاد المفرغة (`characters/`, `icons/`)، الخطوط العربية المضمّنة (`fonts/`)، و196 مقطعاً صوتياً عربياً مسجلاً محلياً (`audio/`).
- `tools/validate-content.mjs` — مدقق المخطط والعتبات لجميع الوحدات العشر.
- `tools/e2e-test.mjs` — اختبارات Playwright الشاملة لسطح المكتب والهاتف.

## التحقق والاختبار الآلي

```sh
node tools/validate-content.mjs
node tools/e2e-test.mjs
```
